# Shield Companion

Create a responsive frontend foundation for a master's capstone project named “DeepShield-RAG”.

DeepShield-RAG is a security evaluation and guardrail benchmarking platform for retrieval-augmented AI assistants. Its demonstration use case is an F-1 student policy assistant based on public U.S. government documents.

Build only the frontend shell at this stage. Do not create a backend, database, authentication, Supabase integration, API integration, or fabricated experiment results.

Design requirements:

- Clean, futuristic, professional research-product appearance

- Dark theme with deep navy backgrounds and restrained cyan/blue accents

- High contrast, accessible typography, and readable text

- Responsive desktop, tablet, and mobile layouts

- Avoid excessive gradients, animations, glowing effects, and marketing-style decoration

- Use React, TypeScript, Tailwind CSS, and reusable components

Create:

1. A top navigation bar with the name “DeepShield-RAG”

2. Navigation items: Overview, Policy Assistant, Attack Lab, Experiments, and Evidence

3. A homepage hero section explaining that the platform measures the security and usefulness of RAG assistants

4. Three informational cards: Test Attacks, Compare Defenses, and Analyze Evidence

5. A clearly labeled “Research Prototype” badge

6. A short disclaimer stating that the F-1 assistant is an academic demonstration and does not provide legal advice

7. Placeholder routes or pages for all five navigation items

8. A simple footer showing “Master’s Capstone Research Project”

Do not display invented percentages, experiment scores, customer testimonials, or claims that the system has already been validated.
